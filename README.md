# Examen en línea

Motor de examen sin conexión del Dr. Manuel S. Nazas R., Facultad de Medicina, Universidad
Autónoma de Chiriquí (Panamá).

- Se abre en https://mnazas-glitch.github.io/examenes/ desde el teléfono, la tableta o la laptop.
- **Esta página no trae ninguna pregunta.** El día del examen se le carga un paquete cifrado que
  solo se abre con la clave que el profesor da en el aula. Al terminar, el paquete se retira.
- Las respuestas correctas nunca están aquí: la calificación se hace fuera de esta página.
- Al terminar, el estudiante recibe un código cifrado que solo el profesor puede abrir y lo pega
  en la tarea correspondiente del aula virtual.
- Mientras dura el examen, la página registra cada vez que el estudiante sale de ella (hora,
  duración y pregunta en curso). Se le avisa antes de empezar.

No se aceptan cambios aquí.
